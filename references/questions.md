# questions.md — 問いの棚（調査項目リスト）

## これは何で、何ではないか

**前提: このハーネスは個別企業の深掘り専用。** 対象企業は決まっている状態で使う。
テーマから候補を広く探すスクリーニング用途ではない。

**抜けを潰すための問いの棚**であり、埋めるべきチェックリストではない。
上から順に埋めると、調査が「項目を埋める作業」に堕し、
「何が分かれば結論が変わるか」から逆算する設計思想と衝突する。

使い方は次の通り:

1. **仮説を立てた後に開く。** 先に開くとリストに引きずられ、仮説が凡庸になる
2. P0で**今回使う問いをIDで選ぶ**（共通コアから5〜10問が目安）。選択は `scope.md` に記録する
3. 選ばなかった問いは**レポートに列挙しない**。スコープ宣言で一括処理する
   （`[未調査|意図的|理由:スコープ外|次:次回調査|優先:L]`）
4. 選んだ問いは必要証拠リストに展開し、想定ソースを割り当てる

項目名でなく**問いの形**で書いてあるのは、項目名だと埋める対象になり、
問いだと仮説の起点になるため。

### 対象企業が希少層にいるかを見る問い

需要が伸びても、**全ての層が等しく儲かるわけではない**。拡張のときに最も迂回しにくい層に
利益が集まる。「良い会社か」ではなく「**顧客がこの会社を迂回できるか**」を問う。

対象企業が属する層を特定し、その層について以下を確認する。
（候補を広く探す用途ではない。このハーネスは対象企業が決まっている前提。）

| ID | 問い | 典型的な情報源 |
|---|---|---|
| Q-A13 | 顧客はこの層を迂回できるか。代替設計・内製・別方式で回避できる余地は | 顧客の開示 / 技術動向 / 標準規格 |
| Q-A14 | この層の供給者は何社か。実質的に選べる相手は何社か | 業界統計 / 顧客の調達開示 |
| Q-A15 | 採用までの認定・認証にどれだけ時間がかかるか | 有報「事業の内容」/ 説明会Q&A |
| Q-A16 | 増産の制約は何か（特殊設備・許認可・ノウハウ・材料純度・人材・電力・用地） | 設備投資計画 / 環境影響評価 / 中計 |
| Q-A17 | 顧客の切迫を示す公開証拠はあるか（前払い、能力予約、長期契約、特急料金の受容） | 有報「契約」/ 前受金の推移 / 説明会Q&A |
| Q-A18 | 市場はこの会社を古い業種分類のまま見ていないか | 業種分類 / 過去のセグメント開示との比較 |

**Q-A13〜A16が4つとも「迂回しにくい」方向に揃ったときだけ、希少層と呼ぶ。**
1つ2つで判断すると、単に景気が良いだけの層を希少層と誤認する。

Q-A17は特に有効。**言葉ではなく、顧客が金を先に出しているかどうか**で切迫を測れる。
前受金・契約負債の推移は財務諸表から機械的に追える。

Q-A18は逆張りの起点になるが、**「市場が分かっていない」は最も検証しにくい主張**でもある。
必ず `[推定|根拠:...|確信度:...|反証:...]` の形で書き、事実として書かない。

### 対象企業の位置づけを1文で書く

1. バリューチェーンを層に分ける（最終需要 → システム統合 → モジュール → デバイス →
   プロセス・実装 → 装置・検査 → 材料・消耗品 → 物理インフラ）
2. **対象企業がどの層にいるかを特定する**（複数層にまたがるなら、利益の主な出所の層）
3. Q-A13〜A18でその層の迂回しにくさを確認する
4. 「**この会社は何を制約しているのか**」を一文で書く。
   言えないなら、それは「テーマの恩恵を受けるだけ」の位置にいるということ

分類は4段階から1つ選ぶ: **希少層を支配 / 希少層に供給 / トレンドの恩恵を受ける / 物語だけ**。
この分類はF-02（バリューチェーン内位置と競合マップ）に反映する。

**この判断にスコアや点数を使わない。** 主観的な採点を合計すると、
根拠に遡れない数字が「精密に見える結論」として独り歩きする。
`[推定|根拠:E-xxxx,E-xxxx|確信度:中|反証:～]` の形で、判断とその根拠を分離して書く。

競合を並べる場合も、**比較のための文脈**であって候補選定ではない。
本格的に比較するなら、銘柄ごとに別案件として台帳を作る（`references/workflow.md` の分割基準）。

**このテーマ特有の注意**

- **需要の話は必ず顧客側の一次開示で裏を取る。** サプライヤーの説明資料に書かれた市場見通しは、
  発行体の自称（T2）であって市場データではない
- **「AI関連」という括りで比較しない。** 同じ括りでも、電源設備と半導体前工程では
  収益構造もサイクルも違う。競合比較は同一レイヤー内で行う
- 技術世代・製品名は陳腐化が速い。**問いは構造で書き、固有の製品名を書かない**
  （このリストに製品名が無いのはそのため）

## 棚卸し

- 3案件連続で一度も選ばれなかった問いは削除候補
- 追加は `improve_gate.py` の汎用性ゲートを通してから。特定銘柄由来の問いを直接足さない
- テーマアドオンが12問を大きく超えたら、テーマを分割するか共通コアへ昇格させる
